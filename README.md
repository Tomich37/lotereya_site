# Счастливый бочонок

Автономный сайт для проведения лотереи. Сервер, база данных, интернет и установка программ не требуются.

## Как запустить

1. Распакуйте архив.
2. Откройте файл `index.html` двойным щелчком.
3. Добавьте участников, укажите количество билетов и отметьте пришедших.
4. Настройте приз и нажмите «Вытянуть бочонок».

## Правила розыгрыша

- Каждый билет — отдельный шанс на победу.
- Для главного приза можно выбрать «Только пришедшие».
- Для следующих призов можно переключиться на «Все участники».
- Пустые бочонки не дают победителя: после них нужно тянуть следующий.
- Режим «Исключить человека» убирает все его билеты из последующих розыгрышей.
- Режим «Убрать выигравший билет» оставляет остальные билеты победителя в игре.
- История и список участников сохраняются только в локальном хранилище браузера.

Чтобы начать мероприятие с чистого листа, нажмите «Очистить».
